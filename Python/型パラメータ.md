# 型パラメータに対する変性(variance)について

## 変性とは

型パラメータ(Tなど)に対する変性(variance)とは、型ヒント(mypyなど)において、サブタイプの関係性がどのように伝播するかを制御する。
これにより、Tのサブ/スーパータイプ関係がジェネリック型(List[T]など)にどのように影響するのかを定義する。

## 変性の種類

### 共変(covariant)

型パラメータが読み取り専用の場合に使用する。
サブタイプ関係が同じ方向に伝播する。

```python
from typing import TypeVar
T_co = TypeVar('T_co', covariant=True)

def process(items: list[T_co]) -> T_co: # 出力のみ -> 共変OK
  return item[0]
```

### 反変(contravariant)

型パラメータが書き込み専用の場合に使用する.
サブタイプ関係が逆方向に伝播する。

```python
from typing import TypeVar
T_contra = TypeVar('T_contra', contravariant=True)

def feed(handler: Handler[T_contra], item: T_contra) -> None: # 入力のみ -> 反変OK
  handler(item)
```

### 不変(invariant)

サブタイプ関係が伝播しない。厳密に一致する必要がある。
